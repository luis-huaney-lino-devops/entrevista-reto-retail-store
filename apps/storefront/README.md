# Storefront (pendiente — Fase 3 del plan)

Next.js (App Router), SSR/ISR para catálogo y detalle, `useReducer` para el carrito.
Ver `docs/PLAN.md` secciones 2.2–2.3 y 9.

Cuando se inicialice: `npx create-next-app@latest .` con TypeScript, Tailwind y App Router,
y `NEXT_PUBLIC_API_URL` apuntando al backend Java (`http://localhost:8080` en local).
