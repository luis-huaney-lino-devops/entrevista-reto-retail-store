PROCESO DE SELECCIÓN: DESARROLLADOR FULL STACK
Gracias por considerar la oportunidad de formar parte de nuestro equipo y por dedicar tu
tiempo a realizar este reto técnico.
El objetivo de este ejercicio es conocer tus habilidades técnicas, conocimientos de desarrollo y
capacidad para resolver problemas, así como la forma en que estructuras y planteas una
solución de software.
A continuación, detallamos los requerimientos del reto.
1. RETO: “RETAIL STORE”
El reto consiste en desarrollar un prototipo funcional de un e-commerce, donde los usuarios
puedan explorar productos y realizar las principales acciones de una experiencia de compra
digital.
El desarrollo debe contemplar, las siguientes funcionalidades:
• Visualizar productos en la página principal (Home).
• Consultar información básica de cada producto.
• Agregar productos al carrito de compras.
• Eliminar productos del carrito.
• Actualizar la cantidad de productos seleccionados.
• Visualizar el resumen del carrito, incluyendo cantidades y precios.
• Calcular y actualizar los montos del carrito en tiempo real.
Además de cumplir con los requerimientos mínimos, se valorará tu capacidad para proponer
mejoras e innovaciones que permitan brindar una experiencia de usuario más completa.
Puedes incorporar funcionalidades adicionales como:
• Búsqueda y filtros de productos.
• Categorías y navegación intuitiva.
• Favoritos o lista de deseos.
• Recomendaciones de productos.
• Promociones y descuentos.
• Experiencia de checkout simplificada.
• Chat de atención al cliente.
• Notificaciones de las acciones realizadas.
• O cualquier otra funcionalidad que consideres relevante.
El objetivo no es únicamente cumplir con los requisitos solicitados, sino demostrar tu capacidad
para diseñar y desarrollar una experiencia de e-commerce completa, intuitiva y atractiva.
2. TECNOLOGÍAS REQUERIDAS
El proyecto deberá desarrollarse utilizando las siguientes tecnologías:
Frontend
• React Manejo de estado mediante useState, useReducer o una solución equivalente.
• CSS puro, Tailwind CSS o una tecnología similar.
• Diseño responsive para dispositivos móviles y desktop.
Backend
El backend deberá desarrollarse utilizando una de las siguientes tecnologías:
• Java + Spring Boot
• C# + .NET / ASP.NET Core
El backend deberá exponer una API REST para atender las necesidades del frontend.
3. REFERENCIA DE DISEÑO
Puedes utilizar como inspiración cualquier diseño o mockup de un e-commerce.
Por ejemplo: https://www.magnific.com/es/fotos-vectores-gratis/mockup-tienda-online
El diseño final no tiene que ser una copia exacta del mockup. Se valorará la capacidad de adaptar
la referencia y proponer una interfaz propia.
4. API Y BACKEND
Deberás desarrollar un backend que proporcione las APIs necesarias para el funcionamiento de
la aplicación. Puedes definir libremente los endpoints que consideres necesarios. Como
referencia para la estructura y comportamiento de una API de productos, puedes consultar:
https://fakestoreapi.com/docs
La solución deberá contemplar una adecuada separación entre frontend y backend, utilizando
APIs REST para la comunicación entre ambos.
5. CONTROL DE VERSIONES Y DESPLIEGUE
El proyecto deberá cumplir con las siguientes consideraciones:
Trabaja el proyecto utilizando un sistema de control de versiones publico (github, gitlab etc)
La aplicación deberá estar desplegada y disponible para su revisión. Puedes utilizar la plataforma
de tu preferencia, por ejemplo: Firebase, Vercel, Render, Un hosting, etc. Deberás proporcionar
los enlaces correspondientes al frontend y, si aplica, al backend.
6. USO DE INTELIGENCIA ARTIFICIAL
Puedes utilizar herramientas de Inteligencia Artificial (IA) durante el desarrollo del reto. Sin
embargo, es importante que comprendas el código generado y puedas explicar las decisiones
tomadas durante el desarrollo.
Durante la entrevista podremos realizar preguntas sobre:
• La arquitectura utilizada.
• El funcionamiento del código.
• Las decisiones técnicas.
• El manejo del estado.
• La comunicación entre frontend y backend.
• Las APIs desarrolladas.
• Las validaciones implementadas.
• Las librerías utilizadas.
• Cualquier parte del código que hayas desarrollado con apoyo de IA.
El uso de IA no será un problema; lo importante es que puedas comprender, justificar y
mantener la solución desarrollada.
7. CRITERIOS DE EVALUACIÓN
Durante la evaluación se considerarán, entre otros, los siguientes aspectos:
Fundamentos de programación: Uso adecuado de estructuras y conceptos de programación;
Capacidad de resolver problemas; Manejo de casos de error y validaciones.
Desarrollo Frontend: Conocimientos y manejo de React; Manejo adecuado del estado;
Componentización; Organización de la aplicación; Experiencia de usuario.
Desarrollo Backend: Conocimientos de Spring Boot o .NET; Diseño y desarrollo de APIs REST;
Manejo de validaciones y errores; Estructura y organización del proyecto.
Arquitectura y estructura: Separación adecuada de responsabilidades; Organización y
mantenibilidad del código; Uso apropiado de patrones y buenas prácticas cuando corresponda.
Calidad del código: Legibilidad; Consistencia; Nombres adecuados para variables, métodos y
componentes; Evitar código duplicado; Buenas prácticas de desarrollo.
Documentación: Claridad de las instrucciones de instalación y ejecución; Documentación de
aspectos relevantes de la solución.
Experiencia de usuario: Diseño visual; Facilidad de navegación; Responsive design; Fluidez de
las interacciones; Propuestas adicionales que aporten valor al producto.
8. ENTREGA
El proyecto deberá ser enviado dos horas antes de la entrevista presencial.
La entrega deberá incluir:
• URL del repositorio.
• URL del proyecto desplegado.
